Two ways to open Apex DuoView

The opening has two parts. While the app starts, iOS shows the launch screen, which Apple allows only as a still image, so each still below is drawn to match the first frame of its intro and the hand-off is invisible. The intro then plays once per launch, takes about 1.5 seconds, and a tap anywhere skips it. Text appears only in the intro, because launch screens should carry no text. Screens are drawn to the Duo's real shapes: the inner screen open flat (951 × 669 pt, fold down the middle), the inner screen turned for laptop use (669 × 951 pt, fold across), and the closed outer screen, whose real size is still to be measured.

After you choose

What I'd generate

One set of four images for the outer screen per direction, and an optional landscape set for the inner screen; the laptop view crops that landscape set to portrait. You pick one image from a set and it replaces the stand-in in every frame. Every prompt avoids vehicles, liveries, people, text, flags and any racing-series or team marks.

ANight circuit

  1. Set 1 · portrait, outer screen (ratio set after you measure)

    Night-time motor racing circuit seen from a low, elevated angle. Empty wet asphalt sweeping through a long corner low in the frame, red-and-white kerbs, floodlights with a warm sodium glow in a dark sky. Deep blacks, cinematic, high contrast, still and calm, no motion blur. Upper-middle of the frame dark and empty for a logo. No vehicles, no people, no light trails, no text, no logos, no flags, no sponsor boards.

  2. Set 2 · landscape about 10:7, inner screen (optional)

    The same night circuit scene in landscape framing, about 10:7, a wider view of the corner in the lower third. Keep the left half and the centre dark and calm, with the subject near the centre so a portrait crop still works. No vehicles, no people, no light trails, no text, no logos, no flags, no sponsor boards.

The app draws the red and white light trails and the logo glow, so the image stays a still, empty track.

CMinimal

  1. Set 1 · portrait, outer screen (ratio set after you measure)

    Near-black matte surface with a faint carbon-weave texture and a soft vignette. Minimal, premium, almost empty, monochrome. No light streaks, no text, no logos, no vehicles, no people.

  2. Set 2 · landscape about 10:7, inner screen (optional)

    The same near-black carbon-weave surface in landscape framing, about 10:7, with a soft vignette, monochrome and almost empty. No light streaks, no text, no logos, no vehicles, no people.

The app draws the purple sweep and the underline, so the image is only the dark surface.
